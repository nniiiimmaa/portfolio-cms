# CV Management System

A modern Content Management System designed to manage and maintain personal CV (Curriculum Vitae) information dynamically.

This system provides an administration dashboard where all professional information can be managed, including work experience, education, certifications, skills, projects, testimonials, and contact information. The managed data is then used to generate and display a professional online CV.

---

# 🚀 Features

## CV Content Management

Manage all sections of a professional CV:

- Personal profile information
- About section
- Work experience
- Education history
- Certifications
- Technical skills
- Skill categories
- Projects
- Hobbies and interests
- Testimonials
- Social media links

---

## Professional Experience Management

Manage professional history:

- Company information
- Position
- Employment period
- Current employment status
- Technologies used
- Company logo
- Location
- Multilingual descriptions

---

## Education Management

Manage academic background:

- Institution
- Degree
- Field of study
- Location
- Study period
- Academic score
- Verification links
- Multilingual descriptions

---

## Certification Management

Manage professional certifications:

- Certification title
- Issuing organization
- Issue date
- Expiration date
- Credential ID
- Verification URL
- Certification image

## Project Management

Manage portfolio projects:

- Project title

- Project type
- Project status
- Technologies
- GitHub repository
- Live URL
- Screenshots
- Featured projects
- Display ordering

---

## Skills Management

Organize technical skills:

- Skill categories
- Skill level
- Years of experience
- Featured skills
- Icons
- Descriptions
- Multilingual support

# 🌍 Multilingual Support

The system supports multiple languages for CV content:

| Language | Locale |
|---|---|
| English | en |
| Portuguese | pt |
| Spanish | es |
| German | de |
| Turkish | tr |
| Persian | fa |
| Arabic | ar |

Features:

- Multilingual CV information
- Language-based content management
- RTL support for Persian and Arabic

---

# 📊 Dashboard

The administration dashboard provides an overview of CV activity:

- Total projects
- Received messages
- Recent updates
- Messages statistics
- Visitor statistics

Visitor tracking is handled internally without depending on external analytics services.
